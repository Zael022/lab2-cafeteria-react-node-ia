# Frontend · Mostrador de la cafetería

React (Vite) + React Router. Consume la API de `../backend` y el webhook de n8n.

```bash
npm install
npm run dev      # http://localhost:5173
```

La API debe estar corriendo antes (`npm run dev` en `../backend`). Las direcciones se pueden cambiar copiando `.env.example` como `.env`.

Ver el README principal del repositorio para las vistas, los componentes y las decisiones de diseño.
